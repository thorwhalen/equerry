Research theme: the architecture of an organisation layer over many autonomous agents — the desk, the bus, the schedule, the approval queue — for a framework whose agents are Claude Code sessions on three machines and whose principal reads on a phone.

Cover: reference architectures for coordinating many long-running agents under one principal: event bus vs task board vs hierarchical orchestrator; durable execution engines (Temporal, Inngest, Trigger.dev, Restate, Hatchet) and whether an org layer needs one; orchestration frameworks with hierarchy or manager roles (LangGraph, AG2/AutoGen, OpenAI Agents SDK handoffs, Claude Agent SDK subagents, CrewAI hierarchical process, MetaGPT SOPs); inter-agent protocols (MCP, A2A, AG-UI, ACP) and what each is for; human-in-the-loop primitives (interrupts, approval queues, HumanLayer, "proposal then confirm" cards) and how they resume; scheduling (cron, routines, event-driven wakeups) and idempotency; the state model (what is the source of truth for an item, who may write it, how overrides are logged). Deliverable: a comparison table, a recommended reference shape (components, their contracts, what is data vs what is an agent), the minimum viable version, and the standard terminology (so the code uses the words the field uses).

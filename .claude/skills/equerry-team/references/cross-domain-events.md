# Cross-domain events

Some asks are events that touch several teams at once. Small companies handle them with one named owner per item (the "directly responsible individual") and a checklist per recurring event. Here the **secretary is the DRI** (in a host without one, the calling session is): it opens one item per team touched, each with its team's checklist lines, and closes the event when every item is closed. Teams do not message each other; the DRI carries what one team needs from another.

How to run one: name the event and its date; copy the event's checklist below; give each line to the team in brackets as an ask through `equerry-team` (one coverage line per team); collect the results under one heading in the brief; close the event when the last item closes.

Jurisdiction labels: `[US]`, `[FR]`, `[EU]`. The sources behind each line are in the teams' domain skills (`equerry-<team>/references/sources.md`); re-verify any date-bound item there before relying on it. Last checked 2026-11-09.

## Equity grant

Teams: people, legal, finance, ventures.

- [ ] [legal] board or shareholder approval of the grant prepared for counsel
- [ ] [finance] `[US]` a current 409A valuation exists for the grant date
- [ ] [legal] grant agreement drafted by counsel from the plan's form
- [ ] [people] `[US]` 83(b) election filed within 30 days if shares are subject to vesting; `[FR]` BSPCE conditions checked
- [ ] [ventures] cap table updated on the venture page
- [ ] [finance] `[US]` QSBS holding-period dates noted

## Fundraise (SAFE or priced round)

Teams: ventures, legal, finance, people.

- [ ] [ventures] instrument and template chosen (post-money SAFE or priced round), with the reasons
- [ ] [legal] `[US]` Form D and state notices calendared after the first sale
- [ ] [finance] `[US]` 409A refreshed after the round
- [ ] [ventures] data room assembled and current
- [ ] [ventures] investor-update list updated
- [ ] [people] any option pool change reflected in offers in flight

## New consulting or fractional client

Teams: bizdev, legal, finance, people.

- [ ] [legal] conflict check against the venture map: non-competes, IP assignments and confidentiality the principal already owes
- [ ] [legal] master agreement and statement of work: the principal's background IP listed and retained, deliverables' IP stated, out-of-scope written
- [ ] [finance] tax forms exchanged; invoicing, payment terms and VAT treatment set
- [ ] [people] subcontractor papers if anyone else works on it (classification, IP assignment, confidentiality)
- [ ] [bizdev] pipeline entry closed as won, with the scope and the rate

## Training engagement in France

Teams: bizdev, finance, legal.

- [ ] [bizdev] `[FR]` funding route known: Qualiopi certification is required for OPCO or CPF funding
- [ ] [legal] `[FR]` training-provider activity declaration in place
- [ ] [finance] `[FR]` data for the annual pedagogical and financial report (BPF) captured as the training is delivered

## Product launch

Teams: product, marketing, legal, engineering, finance.

- [ ] [marketing] positioning written (the five components) before any launch copy
- [ ] [legal] `[EU]` privacy notice and record of processing current
- [ ] [legal] `[US]` COPPA review if any user may be under 13
- [ ] [legal] `[EU]` AI transparency duties checked if the product has AI features
- [ ] [engineering] security baseline met (the engineering skill's checklist)
- [ ] [finance] app-store or marketplace tax set-up done
- [ ] [product] kill-or-continue date written before launch

## Open-source release or licence change

Teams: engineering, legal, marketing.

- [ ] [engineering] licence chosen from the OSI list and REUSE-compliant headers
- [ ] [engineering] contributor terms chosen (DCO or CLA)
- [ ] [legal] `[EU]` Cyber Resilience Act scope memo if a venture monetises the project
- [ ] [legal] a licence change on a released project goes to counsel (escalation line)
- [ ] [marketing] announcement written and scheduled

## New contractor

Teams: people, legal, finance.

- [ ] [people] classification tested: `[US]` common-law control test; `[FR]` subordination test (requalification is retroactive)
- [ ] [legal] IP assignment and confidentiality signed before work starts
- [ ] [finance] tax form collected; payment set up
- [ ] [people] access granted with an offboarding date or review date

## Taking a new role in a venture

Teams: ventures, legal, finance.

- [ ] [ventures] role documents (offer, board appointment, advisory agreement) collected
- [ ] [legal] corporate-opportunity and conflict review against the other ventures
- [ ] [ventures] time budget set on the venture page
- [ ] [finance] tax consequences of any equity noted for the accountant

## Year end

Teams: all.

- [ ] [legal] [finance] next year's statutory calendar generated from the calendar references and the venture pages
- [ ] [ventures] every venture page reviewed
- [ ] every team: engagement letter re-read; `review_by` renewed or the letter paused
- [ ] every team: `equerry-team-review` run, with the year's false-coverage rate
